Registry/boxing, packaging, milk/petrol и производственная цепочка проверены в
свежем игровом процессе. Ранний boxing PASS был недостаточен: неизвестные теги
объединяли чужие предметы через null. Authored группы теперь регистрируются до
ScriptManager.Load; generic boxing ограничен 35 проверенными материалами и
запрещает потерю состояния. Native проверки также выявили различие category
`Item` и script type `Normal`, а также отсутствие глобального `next` в игровом
Lua. Predicate использует реальные category и `pairs`; все 12 сценариев прошли.

Crafting harness проверяет расход шести банок и четырёх апельсинов, получение
20 семян из одного початка, упаковку 50 предметов, шесть бутылок пива,
нарезку частично съеденного сыра с сохранением свежести и общего питания,
копчение с жидкостью, возврат только опустевших мисок и сохранение щипцов при ковке.
Используется native валидация и обработка рецептов; навыки лабораторного персонажа
поднимаются обычным API опыта, ограничения рецептов не отключаются.

## Условия и пределы проверки

Игровые прогоны используют отдельные `cachedir` и миры вне репозитория.
MP сервер слушает `127.0.0.1`, UPnP отключён. Пользовательские сейвы не используются.
Это контрольные прогоны, а не доказательство всех комбинаций 3636 рецептов.
Проверка других модов, долгой игры и нескольких одновременных клиентов ещё нужна.

Проверка загрузки старой кольчуги после настоящего сохранения прошла.
Старый ID оставлен `base:normal`; новое носимое состояние использует отдельный ID.
Смена Java-класса под старым ID недопустима: native loader может потерять запас.
Лабораторный мир содержал старые экспериментальные экземпляры с изменённым
классом. Для save/reload выбран контрольный персонаж с исходным normal ID;
его native save BLOB не изменялся. Пользовательские сейвы не затрагивались.
Не все клинки уже имеют оригинальную геометрию. Для 48 world references без
достоверной геометрии оставлена native 2D-иконка, список в WORLD_MODEL_FALLBACKS.json.
У новой 3D-ловушки legacy взрывная механика сохраняется. Native загрузка и
отображение нового .x экспорта проверены для предмета на земле. Вооружённое
устройство использует штатный PlacedSprite; его размещение, датчик и однократное
удаление проверены в SP. Повреждение зомби и срабатывание в MP не измерялись.
Конверсия собственных static meshes и особенности UV описаны в
[pipeline](STATIC_MESH_PIPELINE.md), данные бензопилы — в
[manifest](CHAINSAW_PIPELINE.json).
Коррекция размеров ящиков описана в [проверке геометрии](PLANTER_SCALE.md).
Статический [аудит достижимости](REACHABILITY_AUDIT.md) отделяет восстановленные
активные цепочки от 79 старых compatibility/выведенных из использования IDs.
Граф не доказывает фактическую частоту лута. Новые редкие веса 0,1–0,2 —
явно задокументированное решение по доступности, а не приписанные upstream значения.

## Воспроизведение

Статические/Lua проверки: `python -m unittest discover -s tools -p 'test_*.py'`
(нужен `lupa.lua51`). `python tools/parse_hcr.py` требует установленную игру для
проверки vanilla IDs. `lab_smoke.lua`, `lab_crafting.lua`, `lab_books.lua`,
`lab_save.lua` и `lab_mp.lua` — только для отдельного тестового мода HCRLab,
в релизную папку их не копируют. MP harness включается явно на обоих endpoints.

Исходные timer/recipe правила сверены с
[Hydrocraft commit 917d37d](https://github.com/brosseaualex/Hydrocraft/tree/917d37d4ed526f429e1525316c9fab487bbf7257).
Результаты fal и обработка ассетов записаны в [provenance](ASSET_PROVENANCE.json).
Сырые генерации, приватный Java-референс и полные игровые логи остаются вне repo.

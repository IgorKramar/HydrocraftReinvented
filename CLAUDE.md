# CLAUDE.md

Ориентировка для агентов и новых разработчиков. Подробности — в документах,
на которые ссылается этот файл; здесь только то, что нужно знать до первой правки.

## Что это

Порт мега-мода **Hydrocraft** (B41) на Project Zomboid **Build 42.20+**.
Репозиторий — сам мод: содержимое `common/` копируется в
`%USERPROFILE%\Zomboid\mods\HydrocraftReinvented\`. Сборки нет, компиляции нет,
тестов в привычном смысле нет — проверка идёт запуском игры.

Масштаб: 5 196 предметов, 3 590 рецептов, 121 схема починки, 12 474 строки Lua,
5 679 текстур, локализация на 10 языков.

## Команды

```sh
# аудит (перед каждым коммитом, трогающим скрипты)
python3 tools/parse_hcr.py --game "<путь к Project Zomboid>"   # или PZ_GAME_DIR
python3 tools/variant_b.py        # недостижимые предметы, некрафтуемые рецепты
python3 tools/analyze_gaps.py     # битые ссылки

# документация (требует установленной игры — иначе откажется писать)
python3 tools/build_xlsx.py
python3 tools/gen_flowcharts.py
```

Каталог игры ищется в порядке: `--game <путь>` → `PZ_GAME_DIR` → типовые места
установки Steam. Без него работает только `parse_hcr.py`, и то с предупреждением.

## Что нужно знать до первой правки

**Философия порта — «дополнить, не задублировать».** Кузнечное дело, гончарство,
кладка, стекло, разделка и животноводство отданы ванильным навыкам B42
намеренно. Не возвращайте их.

**Мост OnCreate.** Сигнатуры B41 и B42 разные, 282 функции работают через
обёртку в `lua/server/zzz_HCR42_RecipeCode.lua`. Новая функция обязана быть
заведена туда (`HCR42["Имя"] = wrap("Имя")`), в скрипте ссылка идёт
на `OnCreate = HCR42.Имя`.

**Никаких `Recipe.OnCreate.*`.** В B42 этой таблицы нет: объявление через неё
падает при загрузке и обрывает остаток файла. Шесть таких мест ещё осталось
в коде — они в списке багов.

**Порядок загрузки — алфавитный**, отсюда префиксы `zzz_`.

**Имена рецептов уникальны** по всему моду: совпадение затирает предыдущий рецепт.

**Русская локализация покрывает 100 %** предметов и рецептов. Новый предмет без
русского имени — это регресс, `parse_hcr.py` его покажет.

**Номер tiledef `hcBuilding 591`** записан в сейвы игроков, менять нельзя.

**`modversion` в `common/mod.info`** обновляется при каждом релизе — по нему
игра и Мастерская определяют версию, и она уже отставала на три релиза.

## Ветка и пул-реквесты

Перед **каждым** пушем проверяйте, не влит ли уже пул-реквест текущей ветки.
Влитый PR закрыт навсегда: дописывать в его ветку нельзя — коммит повиснет
между релизами, а описание PR перестанет соответствовать тому, что в нём было.

```sh
git fetch origin main
git merge-base --is-ancestor HEAD origin/main && echo "ветка влита — начинайте заново"
git log --oneline origin/main..HEAD          # что в ветке сверх main
```

Если влит — ветка начинается заново от свежего `main` (имя то же), и на новую
работу открывается новый PR:

```sh
git fetch origin main && git checkout -B <ветка> origin/main
```

Описание влитого PR не редактируется задним числом: это запись о том, что
было влито, а не место для новостей.

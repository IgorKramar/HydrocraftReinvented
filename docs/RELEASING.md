## Нумерация

`МАЖОР.МИНОР.ПАТЧ`, как в истории мода:

- **патч** (1.5.6 → 1.5.7) — исправления по репортам, без новых систем;
- **минор** (1.4.0 → 1.5.0) — крупная подсистема или ревизия целого пласта
  (обучение, лут, баланс опыта);
- **мажор** — смена того, из чего мод сделан (жидкости, станции-сущности).

Планы по мажорам — в [ROADMAP.md](../ROADMAP.md) и [VISION.md](VISION.md).

## Перед сборкой

### 1. Аудит

```sh
python3 tools/parse_hcr.py --game "<путь к Project Zomboid>"
python3 tools/variant_b.py
python3 tools/analyze_gaps.py
```

Смотрим:

- **переопределения предметов** — `parse_hcr` печатает `items=N (определений M)`;
  M больше N означает предметы, объявленные дважды. Движок оставит последний
  по алфавиту файлов, ваш — не обязательно тот;
- **недостижимые предметы и некрафтуемые рецепты** — не выросли ли числа
  относительно прошлого релиза (ориентир v1.5.5: 803 → 101 некрафтуемых);
- **битые ссылки** — рецепты, ссылающиеся на несуществующие предметы.

### 2. Локализация

Русский покрывает 100 % предметов и рецептов — разрывов быть не должно.
Проверяется тем же `parse_hcr.py`:

```
ru items covered=5196/5196
ru recipes covered=3590/3590
```

### 3. Версия в манифесте

`common/mod.info`, поле `modversion` — **по нему игра и Мастерская определяют
версию**. Оно уже отставало на три релиза (1.5.0 при фактических 1.5.7):
поле легко забыть, потому что игра не жалуется.

Заодно проверьте числа в описании `mod.info` и в README: количество предметов
и рецептов там зашито текстом и тоже устаревает.

### 4. Документация

```sh
python3 tools/build_xlsx.py       # docs/HCR_Database.xlsx
python3 tools/gen_flowcharts.py   # docs/FLOWCHARTS.md
```

Оба генератора требуют модель, собранную **при установленной игре**: без
ванильных переводов ванильные предметы подписываются идентификаторами
(`Stone2` вместо «Камень»). Скрипты откажутся писать в `docs/` и скажут об этом;
осознанный обход — `--allow-missing-vanilla`.

Версия в шапке этих документов подставляется из `mod.info` — ещё одна причина
обновить его раньше.

### 5. CHANGELOG

Запись на двух языках, русский сверху. Формат — как в предыдущих: заголовок
`### vX.Y.Z — ГГГГ-ММ-ДД`, дальше жирным строкой суть, потом список правок
с числами. Числа — не украшение: по ним потом видно, что именно изменилось.

Упоминайте авторов репортов поимённо — это единственная благодарность,
которую мы можем дать.

## Сборка и публикация

Мод — это содержимое `common/`. Локальная проверка:

```
%USERPROFILE%\Zomboid\mods\HydrocraftReinvented\   ←  сюда кладётся common/*
```

Публикация в Мастерскую идёт **внутриигровым инструментом** (Steam Web API
загружать не умеет). Перед загрузкой:

- запустите игру с включённым модом и посмотрите отчёт об ошибках (`F11`) —
  красных строк с упоминанием Hydrocraft быть не должно **на старте**,
  до всякого крафта: ошибки загрузки видны сразу;
- проверьте на старом сейве, а не только на новом мире, если релиз трогает
  предметы или рецепты;
- если релиз меняет структуру предметов (как планируемая миграция на жидкости),
  нужен конвертер на загрузке — иначе у игроков пропадут запасы.

## После публикации

- Ответьте в треде багрепортов тем, чьи сообщения закрыты этим релизом,
  с номером версии. Свод открытых и закрытых репортов — в [FEEDBACK.md](FEEDBACK.md).
- Обновите список совместимости на странице Мастерской, если появились
  или исчезли конфликты.
- Тег в git по желанию, но ветка релиза должна быть влита в `main`.

## Что ломается чаще всего

| Симптом | Причина |
|---|---|
| Красные ошибки на старте, до крафта | ошибка уровня файла: `Recipe.OnCreate.*`, обращение к снятому API |
| «Object tried to call nil in X» | функция не заведена в мост `HCR42[...]` либо файл оборвался выше по тексту |
| Рецепт есть, но не крафтится | ингредиент недостижим — ловится `variant_b.py` |
| Предмет невидим в руках | меш есть, блока `model` нет |
| Предмет не спавнится | вес в дистрибуциях ушёл ниже 0.1 |
| Ассет не грузится на сервере | регистр в имени файла: linux чувствителен, Windows нет |
